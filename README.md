# EDUVERSE 3D — Multiplayer MVP

## Render sozlamalari
- Language: Node
- Branch: main
- Root Directory: bo‘sh qoldiring
- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variables: hozircha kerak emas

## Fayllar
- `package.json`
- `server.js`
- `README.md`
- `public/index.html`

Bu telefon va kompyuter brauzerlarida ishlaydigan boshlang‘ich multiplayer viktorina. Xona yaratish, xona kodi bilan qo‘shilish, 40 kishigacha xona limiti, real vaqt ishtirokchilar ro‘yxati, 5 ta namunaviy savol va reyting mavjud.

Bu hali to‘liq mahsulot emas: haqiqiy 3D avatar dunyosi, 20 ta o‘yin turi, o‘qituvchi paneli, akkauntlar, ma’lumotlar bazasi va 40 qurilmali yuklama testi keyingi ishlar hisoblanadi. Xonalar server xotirasida turadi va server qayta ishga tushganda yo‘qoladi.
